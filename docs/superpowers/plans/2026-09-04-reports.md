# Acknowledgment and Reports Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development task-by-task.

**Goal:** Collect real pre-service acknowledgment and generate shareable, immutable, versioned local PDF reports.

**Architecture:** Add optional versioned acknowledgment/report payloads to the existing SwiftData job. Capture documents remain the sole source for photos and findings. Snapshot all visible report inputs when sealing; store new PDF files separately, record SHA-256, and never overwrite prior versions. Acknowledgment is tied to a fingerprint of pre-service content so edits cannot silently reuse an unrelated signature.

**Tech Stack:** SwiftUI, SwiftData, UIKit drawing/PDF, PDFKit, CryptoKit, XCTest; iOS/iPadOS 17+.

**Spec:** `docs/superpowers/specs/2026-09-03-detailhandoff-design.md`

## Global Constraints

- DetailHandoff / com.aiden609906.detailhandoff; USD 9.99 paid download, no subscription, backend, login, analytics, AI or third-party runtime SDK.
- Use the preceding Capture plan's final interfaces. Read its implementation report for any verified signature adjustments.
- No legal-evidence, insurance, warranty or guaranteed-protection claims.
- Original PDF versions and their snapshots are immutable and remain accessible after revisions.
- Missing required photos/skips, absent acknowledgment, changed pre-service content, corrupt evidence and missing image files must block sealing.
- Failed file generation or database save does not advance status or mutate existing report files.

- [ ] Test first: blank signatures and blank unavailable reasons fail; valid multisegment normalized stroke persists through a fresh context; identity of job and before-content changes makes `isCurrent` false; changing only After photos leaves it true; save failure restores payload/timestamp. Fingerprint includes job ID, customer/vehicle/service, Before photo IDs/paths/time, Before skips and findings with deterministically sorted encoding. Do not include mutable After fields or workflow timestamps.
- [ ] Attempt focused XCTest and record missing-tool limitation on Windows.

- [ ] Write tests first for multipage PDF with 40 generated photos, required text extracted with PDFKit, every phase/slot represented, long notes pagination, missing/unreadable referenced asset failure, SHA-256 equality, same-day unique numbering, monotonically increasing version, old PDF unchanged, failed save cleanup, and missing/invalid acknowledgment rejection.
