# Product-name precheck — 2026-09-16

This is a preliminary knock-out search, not legal advice, a trademark opinion, or a reservation of the name.

## Working name

`DetailHandoff` (alternate spacing searched: `Detail Handoff`)

## Checks completed

- Apple’s public U.S. Search API was queried for both spellings. It returned no exact app-name match for either spelling on 2026-09-16. Fuzzy results existed for generic `Detail` terms, so this is not proof that App Store Connect will accept or reserve the name.
- Exact-phrase public web searches for `DetailHandoff`, `Detail Handoff` software/app, and `DetailHandoff` trademark did not surface an exact competing product or registered mark in the indexed results reviewed.
- The official USPTO Trademark Search, WIPO Global Brand Database, and EUIPO/TMview sources were identified for the required interactive follow-up. Their official guidance warns that an exact-word search is only the first step; similar appearance, sound, meaning, commercial impression, and related goods/services must also be considered.

## Decision

`DetailHandoff` can remain the working name for development and draft metadata. **Do not treat it as legally cleared or invest in irreversible launch materials yet.** Before submission, manually search exact and similar forms in the relevant software and business-service classes, including variants such as `Detail Handoff`, `Detail Hand-Off`, `Detailer Handoff`, `Auto Handoff`, and phonetically similar marks. Have a qualified trademark professional review the target storefronts if the name will be a material brand asset.
