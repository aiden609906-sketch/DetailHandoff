# DetailHandoff 真机发布验收清单（中文）

适用版本：V1，iOS/iPadOS 17 及以上。已知设备：iPad Pro 11 英寸（第 2 代），iPadOS 18.7.8。iPhone 仍需另找一台受支持设备补测。

> 这份清单用于以后拿到 Mac、签名能力和可安装构建后执行。现在没有开发者会员也可以准备清单，但不能用它替代真机安装、签名归档或 TestFlight。

## 记录信息

- [ ] 记录测试日期、App 版本、构建号、Git 提交、设备型号、系统版本和剩余存储空间。
- [ ] iPad 和 iPhone 各保留一套截图或录屏；测试数据必须是虚构数据。
- [ ] 每个失败项记录复现步骤、期望结果、实际结果和附件。

## 安装与首次启动

- [ ] 全新安装后能进入 Jobs 空状态，无测试工单、崩溃或启动错误。
- [ ] 相机权限首次允许、首次拒绝、在系统设置中重新允许后均有可理解的结果。
- [ ] 打开并取消系统照片选择器，不出现不必要的完整照片库权限请求。

## 核心工单流程

- [ ] 新建工单，填写虚构客户、车辆、车牌和服务信息。
- [ ] 完成 Before 引导拍摄；验证拍照、导入、重拍、删除和跳过理由。
- [ ] 添加发现项，验证区域、严重程度、备注和照片。
- [ ] 记录客户确认；另测“客户不在场”及原因。
- [ ] 完成 After 拍摄并检查前后照片配对。
- [ ] 预览草稿 PDF、封存报告、分享 PDF、创建修订，确认旧版本没有被覆盖。

## 断网与数据保留

- [ ] 开启飞行模式并关闭 Wi-Fi，完整执行一次新建工单到封存报告；核心流程不应依赖网络。
- [ ] 在工单进行中强制退出 App，重新打开后确认文字、照片、发现项、确认签名/不在场原因均保留。
- [ ] 封存后再次强制退出并重开，确认 PDF 和历史版本仍可打开。
- [ ] 恢复网络后数据不应被意外清空、复制或改变。

## 文件、备份与恢复

- [ ] 导出完整备份到“文件”，分别测试保存成功和取消。
- [ ] 将备份移动到另一个可选位置后执行恢复，核对工单、照片、签名、PDF 和版本历史。
- [ ] 导出工单照片包，核对文件数量、命名和内容。
- [ ] 分享 PDF 后取消系统分享页，App 内报告与版本仍存在。
- [ ] 删除工单后能在“最近删除”中恢复；永久删除需要明确确认。

## 中断、容量和异常

- [ ] 拍照期间锁屏、切后台、旋转设备、来电/系统中断后，App 能恢复或给出明确提示。
- [ ] 低存储空间或文件保存失败时，不丢失原工单，不产生半份封存报告，并能重试。
- [ ] 恢复错误或损坏备份时，现有数据保持不变且错误信息可理解。

## iPad 专项

- [ ] 在 iPad Pro 11 英寸上测试竖屏、横屏、分屏和舞台调度；主操作不能被遮挡或裁切。
- [ ] 检查键盘弹出、隐藏以及长备注输入，保存按钮始终可到达。
- [ ] 商店截图涉及的 Report、Before photos、Condition findings、Acknowledgment、Settings 页面逐一对照。

## 无障碍与可读性

- [ ] 开启 VoiceOver，按阅读顺序走完新建工单、拍摄、确认和报告主路径。
- [ ] 使用较大与最大动态字体，按钮文字、警告和主要状态不能被截断。
- [ ] 开启“降低动态效果”和“增强对比度”复测主要页面。
- [ ] 仅靠颜色不能区分当前步骤、完成状态、严重程度或错误。

## 发布判定

- [ ] iPhone 和 iPad 的全部阻断项通过；任何崩溃、数据丢失、错误封存或无法恢复均为发布阻断。
- [ ] 结果回填到 `acceptance.md`，附精确构建、设备、系统和证据路径。
- [ ] 真机通过不等于可上架；仍需开发者会员、签名归档、App Store Connect、TestFlight 和 App Review。
