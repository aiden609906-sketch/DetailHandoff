CUSTOMER ACKNOWLEDGMENT  
Review the starting condition and selected service with the customer, then record an acknowledgment or note why the customer was unavailable.

SEALED PDF REPORTS  
Preview a draft, seal a version, and create later revisions without overwriting earlier report history. Share the PDF or export the job's photo package when you choose.

LOCAL-FIRST DATA  
No account is required. Core job records stay on the device. Export a full backup and restore it when needed. Deleted jobs remain recoverable for up to 30 days unless permanently removed.

DetailHandoff is a documentation and handoff tool. It does not identify damage automatically or provide legal, insurance, or inspection advice.

## App Review notes

DetailHandoff has no login, subscription, in-app purchase, ads, analytics, or developer-operated backend. The app uses App Store paid-download pricing and contains no additional paywall.

Core job data is stored locally. Camera access is requested only when Take photo is selected. Import uses the system photo picker for user-selected images. Export and sharing open the system share or Files interface.

Suggested review path:

1. Tap + on the Jobs screen and create a job.
2. Select a service and review the configured capture views.
3. Add Before photos using the camera or photo picker.
4. Add a condition finding with an area, severity, note, and optional photo.
5. Record a customer acknowledgment, or use the customer-unavailable path.
6. Add After photos and review the paired evidence.
7. Open Report, preview the draft, seal a report, create a revision, and use Share.
8. Open Settings to review backup, restore, storage, and Recently Deleted.

The data shown in App Store screenshots is synthetic. A clean install starts without jobs. No demo account is required.
